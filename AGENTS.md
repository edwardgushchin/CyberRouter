# CyberRouter

- Рабочий роутер не сбрасывать, не прошивать и не перезагружать ради тестов этого проекта.
- Перед сетевыми задачами читать профили окружения по глобальным инструкциям; текущее состояние проверять заново.
- Не выводить секреты и содержимое `private/`. Зашифрованные части `snapshots/` можно версионировать; ключи и plaintext нельзя.
- Не распаковывать rootfs поверх хоста. `deploy` применим только к чистому устройству с совпадающими board, release, revision и kernel.
- Сохранять исходные локальные проекты и прежние snapshots. Новый capture — новый каталог; не объявлять физическое восстановление проверенным по файловому сравнению.
- После правок: `sh tools/test.sh`, `git diff --check`, проверка отсутствия секретов. Production-зависимости без согласования не добавлять.
- Новые записи памяти — только по прямой просьбе пользователя. Документацию проекта обновлять по фактическому состоянию.
