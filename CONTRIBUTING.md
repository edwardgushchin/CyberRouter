# Изменения

Отвечаем и ведём документацию по-русски. Используем Python stdlib и имеющиеся системные инструменты; новые production-зависимости требуют согласования.

Перед работой с живой сетью читаем действующие `SYSTEM_PROFILE.md`, `ROUTER_PROFILE.md` и README окружения, проверяем динамическое состояние. Не перезагружаем рабочий роутер ради теста восстановления. Исходники меняем в `components/`; live-снимок обновляем отдельным захватом после проверки фактического поведения.

Для каждого изменения инструментов: `sh tools/test.sh`, `git diff --check`. Проверки с `--router` и `check-on-router.py` требуют доступного оборудования и выполняются отдельно. Они не входят в CI. Если код меняет маршрутизацию, проверяем клиентское соединение и работающие потоки, а не только синтаксис.

Перед commit запускаем `python tools/check-repository.py`. Ключи, расшифрованные tar, приватные IP/параметры VPN и токены не добавляем. Нельзя обходить `.gitignore` через `git add -f private`. Новая точка восстановления содержит manifest, ciphertext-части и отчёт; конкретный plaintext остаётся приватным.
