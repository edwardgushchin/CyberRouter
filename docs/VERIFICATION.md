# Проверка комплекта — 9 сентября 2026

## Выполнено на реальном сохранённом состоянии

- Скачан официальный образ OpenWrt для GL-MT6000 и проверен по опубликованной SHA-256. Источник и точный хеш: `firmware/source.json`.
- Получены полный persistent rootfs, overlay, ROM, sysupgrade backup, пакеты, службы и прежние локальные архивы. Зашифрованный комплект разбит на 6 частей по максимум 48 MiB.
- Финальный ciphertext расшифрован отдельным проходом. SHA-256 всех шести основных архивов совпали с исходным захватом, включая историю, локальные проекты и SSH-доступ.
- Реконструкция `ROM + overlay − удалённые базовые пути` совпала с захватом: **3 146 записей, 2 341 обычный файл, 437 ссылок**. Проверены байты, пути, ссылки, mode, uid и gid. Применяются **1 948 записей overlay и 22 удаления**.
- На самом Flint 2 в отдельном `/tmp` восстановлены ROM и **сгенерированный** `restore.tar.gz`. BusyBox успешно распаковал его и проверил SHA-256 восстановленных файлов, включая необычные имена из старых архивов.
- В этой отдельной файловой системе через chroot штатный ARM-бинарник Xray проверил активную конфигурацию и все три профиля. UCI прочитал настройки, shell проверил синтаксис скриптов.
- Ни одна служба из chroot не запускалась. Прокси-процессы рабочего роутера сохранили PID; временная файловая система удалена. Применения firewall, перезагрузки и сброса рабочего устройства не было.
- Открытые файлы проверены на совпадения с 18 уникальными значениями реальных Xray-подключений из снимка: совпадений нет. Ключ восстановления исключён из Git; отдельная копия совпадает и имеет права `0600`.

## Автономные тесты

Проверяются:

- Сборка файловой системы на искусственном профиле, права/ссылки, удаления, имена с CR и не-UTF-8 байтами.

## Граница доказательств

**Полный цикл «прошить чистый запасной роутер → восстановить → загрузиться → подключить клиента» пока не выполнялся.** Файловая реконструкция и нативная проверка конфигураций прошли, но не заменяют физическую приёмку загрузки, Wi-Fi, WAN и VPN после восстановления. Рабочий роутер ради такой проверки не сбрасывался.

Go-код joiner перенесён без изменения поведения; закреплённый существующий relay включён для будущей пересборки. В этой сессии Go toolchain отсутствовал, поэтому Go-тесты и новая сборка не запускались. Для точного восстановления применяется уже установленный и сохранённый ARM64-бинарник.

GitHub Actions ещё не запускался на GitHub. Локальный CI-equivalent набор запускается без секретов и подключения к роутеру. Другая модель требует отдельной адаптации и проверки по `MIGRATION.md`.
